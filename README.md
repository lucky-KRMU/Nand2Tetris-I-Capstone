## 🛠️ Part A: Build the Computer (`Part-A/`)

The Hack computer is built using three interconnected HDL chips:
1. **`Memory.hdl`**: Memory address space controller mapping addresses `0x0000–0x3FFF` to RAM16K, `0x4000–0x5FFF` to the Screen memory map, and `0x6000` to the Keyboard. Implemented using two-stage `Mux16` and `DMux` routing to eliminate sub-bus endianness issues.
2. **`CPU.hdl`**: Decodes A-instructions and C-instructions, routes ALU operations (`zx`, `nx`, `zy`, `ny`, `f`, `no`), handles conditional jumps (`j1`, `j2`, `j3`), controls internal registers (`ARegister`, `DRegister`, `PC`), and strictly gates `writeM` with `instruction[15] AND instruction[3]`.
3. **`Computer.hdl`**: Integrates `ROM32K`, `CPU`, and `Memory` into a Harvard architecture platform.

### How to Run Hardware Simulator Tests
1. Open the **Nand2Tetris Hardware Simulator** (or navigate to the **Hardware Simulator** tool in the [Nand2Tetris Web IDE](https://nand2tetris.github.io/web-ide)).
2. Open the `Part-A/` directory.
3. Load and run each test script sequentially:
   * `Memory.tst` $\rightarrow$ verifies `Memory.hdl`
   * `CPU.tst` $\rightarrow$ verifies `CPU.hdl`
   * `ComputerAdd.tst` $\rightarrow$ verifies `Computer.hdl` executing `Add.hack`
   * `ComputerMax.tst` $\rightarrow$ verifies `Computer.hdl` executing `Max.hack`
   * `ComputerRect.tst` $\rightarrow$ verifies `Computer.hdl` executing `Rect.hack`
4. Set speed to **Fast** and press **Run**. All tests finish with:
   ```text

   ```

## 🐍 Part B: Python Hack Assembler (`Part-B/`)

The assembler (`assembler.py`) translates `.asm` assembly files into 16-bit binary `.hack` machine code:
* **Pass 1**: Strips comments and whitespace, tracks ROM instruction numbers, and records label symbols `(LABEL)` with their ROM target addresses.
* **Pass 2**: Translates instructions into 16-bit binary strings. Predefined symbols (`SP`, `LCL`, `R0–R15`, `SCREEN`, `KBD`) and labels are resolved; new variables are sequentially allocated RAM addresses starting at `16`.
* **Extra Feature ($K \bmod 3 = 0$)**: Automatically generates a formatted `symbols.txt` file detailing:
  * User-defined ROM labels
  * User-defined RAM variables
  * Complete resolved symbol table

## ⬛ Part C: Interactive Box Application (`Part-C/`)

`Box.asm` implements an interactive graphics program:
* **Trigger**: Constantly checks `RAM[KBD]` (`address 24576`).
  * If a key is pressed (`RAM[KBD] != 0`): `color = -1` (`0xFFFF` / black).
  * If no key is pressed (`RAM[KBD] == 0`): `color = 0` (white / clear).
* **Target Coordinates**:
  * Row $42$: base address $\text{SCREEN} + 32 \times 42 = \mathbf{17728}$.
  * Height: **20 rows** (rows 42 to 61).
  * Width: **48 pixels** (writes words 0, 1, and 2 from left border of each row).
* **Compilation**: Compiled using **our custom `assembler.py`** from Part B into `Box.hack`.

### How to Run in the CPU Emulator
1. Open the **Nand2Tetris Web IDE** (or desktop suite) and select the **CPU Emulator** tab.
2. Click **Load Program** $\rightarrow$ select `Box.hack`.
3. Set the view to **Screen** to display the virtual $512 \times 256$ monitor.
4. Set the simulation speed slider to **Fast**.
5. Click **Run (▶)**.
6. Click into the keyboard area and **press/hold any key**:
   * A solid black $48\text{px} \times 20\text{px}$ rectangle immediately appears at row 42 against the left margin.
   * Release the key to watch the box instantly disappear.

## 💡 Viva Voce Quick-Reference (5-Minute Defense)

Be ready to perform live code modifications on the spot during the viva:

1. **Move the box down by $N$ rows (e.g., down 10 rows):**
   * Change starting address in `Box.asm` (line 38):
     $$\text{New Address} = 17728 + (32 \times 10) = \mathbf{18048}$$
   * Update `@17728` to `@18048`.
2. **Change box height (e.g., from 20 to 30 rows):**
   * Change row counter in `Box.asm` (line 32): update `@20` to `@30`.
3. **Make the box wider by 1 word (16 pixels wider = 64 pixels total):**
   * Add a 4th word write in `ROW_LOOP`:
     ```assembly
     @row_addr
     A=M+1
     A=A+1
     A=A+1
     M=D
     ```
4. **Recompile after editing:**
   ```bash
   python3 Part-B/assembler.py Part-C/Box.asm Part-C/Box.hack
   ```
